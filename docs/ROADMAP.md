# 🗺️ Project Roadmap

This document outlines the high-level trajectory of the JobTrackr API.

## Current Status: Phase 1 (Core Infrastructure)

Focusing on establishing a solid foundation with FastAPI, PostgreSQL, and SQLAlchemy. Implementing the primary CRUD operations for Companies and Applications.

## Upcoming Milestones

- **Phase 2:** Security, Quality Assurance, and Basic UI. Introduction of JWT Authentication, Pytest for test-driven development, and a simple frontend logic.
- **Phase 3:** Enterprise Features. Integration of Redis for caching, Celery for background tasks (e.g., email reminders for interviews), advanced CI/CD pipelines, and a React frontend.

_See `PHASES.md` for a granular breakdown of technical tasks._
