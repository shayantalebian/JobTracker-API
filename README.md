# JobTrackr API 🚀

A robust, RESTful API built with **FastAPI** and **PostgreSQL** to seamlessly track, manage, and organize job applications and interview processes.

## 📌 Overview (Phase 1)

JobTrackr API is designed to solve the chaos of the modern job search. In its current phase, it provides the core backend infrastructure to manage `Companies` and `Job Applications` with a One-to-Many relational database architecture.

## 🛠️ Tech Stack (Core)

- **Language:** Python
- **Framework:** FastAPI
- **Database:** PostgreSQL
- **ORM & Migrations:** SQLAlchemy, Alembic
- **Containerization:** Docker, Docker Compose
- **Package Manager:** uv
